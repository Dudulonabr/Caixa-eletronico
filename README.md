# Calculadora de Cédulas

Projeto simples desenvolvido com **HTML, CSS e JavaScript** para calcular a quantidade de cédulas necessária para representar um valor inteiro informado pelo usuário.

## Funcionamento

O usuário informa um valor em reais e o algoritmo percorre uma lista de valores, calculando quantas unidades de cada cédula são necessárias.

```text
100, 50, 20, 10, 5, 2 e 1
```

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Conceitos praticados

- Entrada de dados
- Conversão de tipos
- Validação com `isNaN`
- Arrays
- Laço `for`
- `Math.floor()`
- Operador de resto
- Manipulação do DOM

## Estrutura

```text
Caixa-eletronico/
├── index.html
└── estilo.css
```

## Como executar

Abra o arquivo `index.html` em um navegador e clique em **Calcular Valor**.
